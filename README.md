# demo-herdr

Proyecto de validación de inputs de usuario.

## Funciones disponibles

| Función | Descripción |
|---------|-------------|
| `validateUsername(username)` | Valida formato de nombre de usuario |
| `validatePhone(phone)` | Valida número de teléfono |
| `validatePassword(password)` | Valida requisitos mínimos de contraseña |
| `validateEmail(email)` | **TODO** — pendiente de implementar |
